# Contract Hub — 実ブラウザ E2E 確認手順書

このドキュメントは、ローカル開発環境でブラウザを使って1契約の業務フローを通し確認するための手順書です。

---

## 前提条件

- XAMPP（MySQL）が起動済み
- PHP 8.4 / Composer インストール済み
- Node.js / npm インストール済み

---

## 1. ローカル起動手順

```bash
cd ~/contract-hub

# 依存インストール（初回のみ）
composer install
npm install

# フロントエンドビルド
npm run build

# DB リセット＆シード（サンプルデータ投入）
php artisan migrate:fresh --seed

# 開発サーバー起動
php artisan serve
```

ブラウザで `http://localhost:8000` を開く。

## 13. ZIP展開確認

ダウンロードしたZIPを展開して、以下の4ファイルが含まれていることを確認：

| ファイル名 | 内容 |
|---|---|
| `contract.pdf` | 契約書PDF（署名者情報含む） |
| `audit-log.csv` | 監査ログCSV（created_at, action, target_type, target_id, ip_address, user_agent） |
| `metadata.json` | 契約情報のJSON（contract_number, company_name, signer_name, signed_at 等） |
| `hash.txt` | 各ファイルのSHA256ハッシュ値 + 生成日時 |

**確認ポイント：**
- `metadata.json` に `signer_name`, `signer_email`, `signed_at` が記録されている
- `audit-log.csv` に `contract_signed_by_external_user` 行がある
- `hash.txt` のSHA256が64文字のハッシュ値になっている

## 注意事項

- 開発環境ではメール送信は `MAIL_MAILER=log` 設定が推奨です（実際にメールは届きません）
- 同意URLはシークレットウィンドウで確認することで、管理者セッションと分離できます
- PDF日本語フォント: `storage/fonts/ArialUnicode.ttf` にフォントファイルを置く必要があります。
  macOS でのセットアップ: `php -r "copy('/System/Library/Fonts/Supplemental/Arial Unicode.ttf', 'storage/fonts/ArialUnicode.ttf');"`
- `php artisan migrate:fresh --seed` を実行するとすべてのデータが初期化されます
