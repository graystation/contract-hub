## 1. ログイン・ログアウト

### ログイン

ブラウザで以下のURLにアクセスします。

```
http://localhost:8000
```

メールアドレスとパスワードを入力してログインします。

### ログアウト

画面右上のユーザー名をクリック → 「Log Out」を選択します。

---

## 2. ダッシュボード

ログイン後に表示されるトップページです。

### 基本情報カード

| カード | 内容 |
|---|---|
| 顧客数 | 登録済み顧客の総数 |
| 案件数 | 登録済み案件の総数 |
| 契約数 | 登録済み契約の総数 |

### 請求・入金サマリー（全期間）

| カード | 内容 |
|---|---|
| 請求総額 | キャンセル以外の請求書の税込合計 |
| 入金済総額 | 全入金レコードの合計 |
| 未入金総額 | 未入金請求書の残高合計 |
| 未入金請求件数 | 下書き・請求済ステータスの件数 |

### 今月の請求・入金

発行日が今月の請求書に絞った集計です。月次の売上確認に使います。

### 未入金請求一覧

入金が完了していない請求書を最大10件表示します。

- **赤背景行** → 支払期限が過ぎている（期限超過）
- **赤字の支払期限** → 期限超過

請求番号をクリックすると請求詳細画面に移動できます。

## 3. 顧客管理

ナビゲーションの「顧客管理」から操作します。

### 顧客一覧

登録済みの顧客が一覧表示されます。会社名をクリックすると詳細画面に移動します。

### 顧客登録

「+ 新規登録」ボタンから登録します。

| 項目 | 必須 | 説明 |
|---|---|---|
| 会社名 | ✓ | 取引先の会社名 |
| 担当者名 | | 担当者の氏名 |
| メールアドレス | | 請求書・同意URL送信先 |
| 電話番号 | | 連絡先電話番号 |
| 住所 | | 所在地 |
| 備考 | | 自由記述 |

> **ポイント：** メールアドレスを登録しておくと、同意URLや請求書をメール送信できます。

### 顧客詳細

顧客の基本情報に加えて、以下が確認できます。

- 請求サマリー（請求合計・入金済・未入金）
- 関連案件一覧（契約数付き）

### 顧客編集・削除

一覧または詳細画面の「編集」ボタンから変更できます。削除時は確認ダイアログが表示されます。

> **注意：** 顧客を削除すると、紐づく案件・契約・請求書もすべて削除されます。

## 4. 案件管理

ナビゲーションの「案件管理」から操作します。

### 案件登録

「+ 新規登録」ボタンから登録します。

| 項目 | 必須 | 説明 |
|---|---|---|
| 顧客 | ✓ | 案件に紐づく顧客を選択 |
| 案件名 | ✓ | 案件の名称 |
| 種別 | ✓ | 広告掲載 / コンサルティング / その他 |
| ステータス | ✓ | 下書き / 進行中 / 完了 / キャンセル |
| 説明 | | 案件の詳細説明 |
| 開始日・終了日 | | 案件期間 |

### 案件詳細

以下が確認できます。

- 案件の基本情報
- 関連契約一覧（ステータスバッジ付き）
- 請求一覧（税込合計・入金済額・ステータス）

## 5. 契約管理

ナビゲーションの「契約管理」から操作します。

### 契約番号

契約番号は **CTR-2026-0001** 形式で自動採番されます（手動入力も可）。

### 契約登録

| 項目 | 必須 | 説明 |
|---|---|---|
| 案件 | ✓ | 紐づく案件を選択（顧客名 / 案件名で表示） |
| 契約番号 | ✓ | 自動採番または手動入力 |
| 契約種別 | ✓ | 例：業務委託契約、広告掲載契約 |
| ステータス | ✓ | 下書き / 送付済 / 締結済 / キャンセル |
| 締結日 | | 契約が締結された日付 |
| 備考 | | 自由記述 |

### 契約ステータスの意味

| ステータス | 意味 |
|---|---|
| 下書き | 作成中・まだ送付していない |
| 送付済 | 相手に送付した・同意URL発行済み |
| 締結済 | 相手が同意済み・契約成立 |
| キャンセル | 契約取り消し |

## 6. 契約PDF・電子同意

契約詳細画面（契約番号をクリック）で操作します。

### PDF生成

「PDF生成」ボタンを押すと、契約書PDFが生成されます。

- 生成されたPDFは `storage/app/contracts/` に保存されます
- SHA256ハッシュが記録されます（改ざん検知用）
- 「ハッシュ検証」ボタンで、保存時からPDFが変更されていないか確認できます

### 同意URL発行

「同意URLを発行」または「URLを発行してメール送信」ボタンを押します。

- 有効期限は**14日間**
- URLは画面上で確認・コピーできます
- 「再発行」すると、古いURLは無効になります

### メール送信（同意URL）

「メール送信」ボタンを押すと、顧客のメールアドレスに同意URLを送信します。

> **前提：** 顧客情報にメールアドレスが登録されている必要があります。

### 外部ユーザーの同意手順

1. 顧客が受信したメールの「契約内容を確認して同意する」ボタンをクリック
2. 契約内容を確認
3. 氏名・メールアドレスを入力し、チェックボックスにチェック
4. 「同意して契約を締結する」ボタンをクリック

同意完了後：

- 契約ステータスが自動で **締結済** に更新されます
- 同意者の氏名・メール・IPアドレス・日時が記録されます
- 署名情報入りの契約書PDFが自動生成されます
- 管理者宛に締結完了通知メールが届きます

### 無効な同意URLについて

以下の場合はエラー画面が表示されます。

| 状態 | 表示 |
|---|---|
| URLが存在しない | URLが見つかりません |
| 有効期限切れ | 同意URLの有効期限が切れています |
| 締結済み | この契約はすでに締結済みです |
| キャンセル済み | この契約はキャンセルされています |

## 7. 請求管理

ナビゲーションの「請求管理」から操作します。

### 請求番号

請求番号は **INV-2026-0001** 形式で自動採番されます。

### 請求登録

「+ 新規作成」ボタンから登録します。

| 項目 | 必須 | 説明 |
|---|---|---|
| 案件 | ✓ | 紐づく案件を選択 |
| タイトル | ✓ | 例：業務委託費用（2026年6月分） |
| 税抜金額 | ✓ | 消費税(10%)は自動計算されます |
| 発行日 | | 請求書の発行日 |
| 支払期限 | | 支払い期限日 |
| ステータス | ✓ | 下書き / 請求済 / 入金済 / キャンセル |
| 備考 | | 自由記述 |

### 請求一覧の表示

| 項目 | 説明 |
|---|---|
| 税込合計 | 税抜金額 × 1.1 |
| 入金済 | 登録された入金の合計 |
| 未入金 | 税込合計 − 入金済 |
| 状態バッジ | 未入金 / 一部入金 / 入金済 / 過入金 / 期限超過 |

### 支払期限の色表示

| 色 | 意味 |
|---|---|
| 赤字 + 「⚠ 超過」 | 支払期限が過ぎている |
| 黄色 + 「⚡ まもなく」 | 7日以内に期限が来る |
| 通常 | 期限まで余裕がある |

### 請求ステータスの意味

| ステータス（DB） | 画面表示 | 意味 |
|---|---|---|
| draft | 下書き | 作成中・未送付 |
| issued + 未入金 | 未入金 | 請求済みだが未入金 |
| issued + 一部入金 | 一部入金 | 一部の入金あり |
| paid | 入金済 | 全額入金済み |
| issued + 過入金 | 過入金 | 請求額を超えた入金あり |
| issued + 期限超過 | 期限超過 | 期限を過ぎた未入金あり |
| cancelled | キャンセル | 取り消し済み |

> **ポイント：** 入金を登録すると、ステータスが自動更新されます（全額入金 → 入金済、一部入金 → 一部入金）。

## 8. 入金管理

請求詳細画面の「入金一覧」セクションから操作します。

### 入金登録

画面下部のフォームから入力します。

| 項目 | 必須 | 説明 |
|---|---|---|
| 入金額 | ✓ | 実際に入金された金額（円） |
| 入金日 | ✓ | 入金が確認できた日付 |
| 入金方法 | ✓ | 銀行振込 / 現金 / クレジットカード / その他 |
| メモ | | 備考（例：振込確認済み） |

### ステータス自動更新のルール

| 入金合計 | 結果 |
|---|---|
| 税込合計と同額以上 | → **入金済** に自動更新 |
| 0円より大きく税込合計未満 | → **請求済**（一部入金状態） |
| 0円（入金削除後など） | 元が入金済なら → **請求済** に戻す |
| キャンセル済み請求 | → 変更しない |

### 過入金について

入金合計が税込合計を超えた場合、請求詳細に警告が表示されます。

```
⚠ 過入金が発生しています（過払い額：¥5,000）
```

エラーではありませんが、顧客に確認することを推奨します。

### 入金の編集・削除

入金一覧の「編集」または「削除」ボタンから操作できます。削除すると入金ステータスが再計算されます。

## 9. 請求書PDF・メール送信

請求詳細画面で操作します。

### 請求書PDF生成

「PDF生成」ボタンを押すと、請求書PDFが生成されます。

- `storage/app/invoices/` に保存されます
- SHA256ハッシュが記録されます
- 複数回生成した場合は全世代が「請求書ファイル一覧」に残ります

### 請求書PDFの内容

生成されたPDFには以下が含まれます。

- 請求番号・発行日・支払期限・ステータス
- 顧客名・担当者・連絡先・住所
- 案件名・種別
- 税抜金額・消費税・税込合計・入金済額・未入金額

### 請求書メール送信

「メール送信」セクションから操作します。

- 送信先メールアドレスが表示されます
- 最新PDFがある場合はそのPDFを添付します
- **PDFが未生成の場合は、送信時に自動でPDFを生成して添付します**
- 「請求書メールを送信する」ボタンで送信

> **前提：** 顧客情報にメールアドレスが登録されている必要があります。

## 10. 監査ログ

契約詳細・請求詳細の最下部に「監査ログ」セクションがあります。

### 記録される操作

| アクション | 意味 |
|---|---|
| 契約書PDF生成 | PDFを生成した |
| ハッシュ検証（一致） | PDFが改ざんされていないことを確認 |
| ハッシュ検証（不一致） | PDFが保存後に変更された可能性あり |
| 同意URL発行 | 外部同意URLを発行した |
| 電子同意完了 | 外部ユーザーが同意した |
| 同意依頼メール送信 | 同意URLをメール送信した |
| 締結完了通知メール送信 | 管理者に通知メールを送信した |
| 請求書作成 / 更新 / 削除 | 請求書の操作 |
| 請求書PDF生成 | 請求書PDFを生成した |
| 入金登録 / 更新 / 削除 | 入金の操作 |
| 請求書メール送信 | 請求書をメール送信した |

### 確認できる情報

- 実行日時
- アクション名
- 実行者のIPアドレス

> **ポイント：** 失敗したアクション（メール送信失敗など）は**黄色**で表示されます。

## 11. よくある操作の流れ

### 新規取引開始から契約締結まで

```
1. 顧客管理 → 新規登録（会社名・メールアドレスを登録）
2. 案件管理 → 新規登録（顧客を選択・案件名・種別を入力）
3. 契約管理 → 新規登録（案件を選択・契約種別を入力）
4. 契約詳細 → PDF生成
5. 契約詳細 → 同意URLを発行してメール送信
6. 顧客が同意 → ステータスが自動で「締結済」に変更
```

### 請求から入金確認まで

```
1. 請求管理 → 新規作成（案件を選択・税抜金額を入力）
2. 請求詳細 → PDF生成
3. 請求詳細 → 請求書メールを送信する
4. 入金確認後 → 請求詳細の入金フォームから入金登録
5. 全額入金 → ステータスが自動で「入金済」に変更
```

### 月次の請求確認

```
1. ダッシュボード → 今月の請求・入金セクションで今月の概況を確認
2. ダッシュボード → 未入金請求一覧で期限超過がないか確認
3. 請求管理 → 一覧で各請求の状態を確認
```
